# 로드맵

> Task 목록과 상태를 한 줄씩 기록한다. 한 행은 plan·impl 한 쌍이다.
> Task 번호는 이 파일이 발급한다. 행을 추가할 때 "다음 Task 번호"를 쓰고 1 올린다. 번호는 재사용하지 않는다.
> 상세 계약과 증거는 각 plan·impl에 있다. 이 파일에는 요약과 링크만 둔다.

## 상태 범례

| 상태 | 의미 |
|---|---|
| ⚪ 예정 | 등록만 됐거나 설계 중, 구현 승인 전 |
| 🔵 진행 | 구현·검증·리뷰 중 |
| 🟡 보류 | 일시 중단. 사유는 비고에 적는다 |
| 🔴 차단 | 외부 의존 때문에 진행할 수 없다. 사유는 비고에 적는다 |
| 🟢 완료 | 개발과 검증이 끝났다. commit·보관 여부는 비고에 적는다 |

## 기록 규칙

- 그룹 제목(마일스톤·버전·백로그)은 프로젝트가 정한다. 그룹이 필요 없으면 표 하나만 둔다.
- 행은 Task 번호 내림차순으로 둔다.
- 문서 열은 이 파일 기준 상대 링크다. 아직 문서가 없는 예정 Task는 비워 둔다. completed로 옮기면 링크도 고친다.
- 커밋·비고 열에는 commit 해시, 릴리즈 버전, 보류·차단 사유 같은 짧은 메모만 둔다.
