# Document Driven Development

문서 주도 개발(Document Driven Development) 스킬이다. Claude Code, Cursor, Codex 등 SKILL.md 형식을 읽는 에이전트에서 쓴다. 실행 기준은 [SKILL.md](SKILL.md)에서 시작한다.

- [실행·승인·stage·완료](references/workflow-guide.md)
- [SubAgent 위임·통합](references/subagent-delegation-guide.md)
- [검증·리뷰](references/verification-guide.md)
- [기록 위치·중복 방지](references/record-routing-guide.md)
- [예시](examples/README.md) · [사용 가이드](DocumentDrivenDevelopment_guide.html)

템플릿과 참조는 필요한 경우에만 읽는다. 프로젝트 템플릿을 사용할 때는 해당 프로젝트 규칙을 확인한다. 이 디렉터리를 다른 실행 환경에 복사할 때는 참조·템플릿까지 포함하고 링크와 동작을 검증한다. 다른 환경의 사본은 자동으로 변경하지 않는다.
