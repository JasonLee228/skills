Skill Guide

Document Driven Development

설계는 승인된 계약과 이유를, 구현 기록은 현재 상태와 실제 증거를 보존합니다.

시작

SKILL.md가 실행 기준의 진입점입니다. 이 페이지는 안내용이며 세부 규칙을 중복 정의하지 않습니다.

설계·TODO·검증안을 함께 승인받고, 직접 수행 또는 순차·병렬 위임으로 구현합니다. 이미 받은 승인은 재사용하며 결과를 검증·리뷰한 뒤 기록·stage·보고합니다.

필요한 가이드

  • 실행 흐름 — 승인, 변경 판단, stage, 외부 반영, 완료와 재개
  • SubAgent 위임과 통합 — 역할, 파일·공유 자원 소유권, 결과 수용
  • 검증과 리뷰 — 실행 증거, 실패 분리, 코드·주석 검토
  • 기록 위치 — 현재 상태와 이력, 선택 문서
  • 초기 설정 · 위험도 · 파일명·보고 · API 명세

템플릿과 예시

기본 문서는 설계와 구현 기록입니다. 해당 없는 선택 항목은 생략합니다.

Task 목록과 상태는 로드맵에 한 줄씩 남깁니다. Task 번호는 로드맵이 발급합니다. 상세 내용은 설계와 구현 기록에만 둡니다.

리뷰 기록과 최종 보고는 독립 보존이 필요할 때 사용합니다. 상세 증거는 한 곳에 두고 링크로 연결합니다.
